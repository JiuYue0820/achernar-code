# Achernar CLI 0.2.0-rc.6

This update improves session deletion in the standalone CLI. The desktop application remains in testing and is not released.

- `/session` shows a clickable **Del Delete** action. The Delete key targets the highlighted conversation, including a filtered selection.
- Confirmation shows the conversation title, ID and deletion scope. **Keep session** is selected by default; Escape cancels.
- Deleting refreshes the list immediately. Deleting the active session clears its conversation view; deleting another session preserves the active conversation and draft. Running-session locks still block deletion, and project files remain intact.
- Rotating Tips and `/shortcuts` now explain session deletion. Added English, Chinese, Russian and Japanese confirmation/help text.
- Session picking has its own module. Target details wrap at narrow terminal widths.
- Installed-package verification now covers explicit deletion confirmation and preservation of project files.

This is an interaction update. Existing model evaluation reports retain their original model IDs, dates and tested source revisions; no new live-model benchmark is claimed.

The npm account is signed in, but the registry rejected the initial rc.5 publication with HTTP 403 requesting additional two-factor publishing verification. Registry availability must be confirmed before advertising a package-name installation or delivered npm update.
