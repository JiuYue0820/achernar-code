# Achernar Code 0.2.0-rc.1

2026-09-26—27 · Windows CLI 候选发布说明

此版本用于安装体验和候选测试，尚未上传公共 npm 仓库。它是独立编程 CLI，不包含完整桌面应用、桌面操控或语音运行时。桌面版还未通过正式发布门槛。

## 这次完成的改进

- 每轮向模型更新剩余额度，最后三轮提醒先完成交付、必要验证和如实说明；终端显示对应提示。耗尽额度仍返回失败，保留会话以便恢复。
- CLI 历史工具正文精简为路径、操作、长度、内容指纹和必要输出，完整记录继续保存在本地。错误、拒绝审批、退出码不会被隐去。
- 中途进度、可收起思考/调用/控制台、最终 Result 和基于实际工具事件的 Run summary 分开显示。补充要求可以加入正在运行的任务。
- 模型列表默认仅显示已配置项，其他服务商模型按需展开。会话支持确认删除；运行锁避免删除或同时写入活跃记录。
- 官方 UI Skill 包含三套原创离线模板，支持通过工具复制后局部改造；18 个官方 Skills、11 个官方 Plugins 完整打包。
- JSONL 输出保留结构化事件、最终结果和错误；参数错误不会再混入普通 stderr。
- 固定直接依赖版本及完整锁文件，包含资源说明；完成独立目录安装和 CMD/PowerShell 入口验证。

## 安装

需要 Node.js 22 或更新版本；本次实际测试为 Windows + Node.js 24.15.0。解压 `achernar-code-0.2.0-rc.1.zip`，在解压目录执行：

```powershell
npm ci
npm link
achernar --version
achernar --json doctor
```

之后进入需要工作的项目目录运行 `achernar`。通过 `/model add` 设置服务商、URL、凭据和模型。安装和模型请求需要相应网络访问；这不是自带模型的离线推理包。

完整使用说明在包内 `README.md`，含实时审批、执行模式、会话、MCP/Skills/Plugins 导入及快捷键。

## 验证结果和边界

- 项目全部 `.test.js`：163 项，161 通过、2 跳过、0 失败；跳过项是需要模型/可执行文件环境的原生 ASR 集成测试。
- 在源码目录以外解压并 `npm ci`，通过本地 HTTP 模型夹具执行真实文件写入、模板复制、shell 验证和官方 MCP 工具；恢复会话、拒绝审批、只读约束、额度耗尽和锁释放均通过。
- CLI 安装后的依赖图经官方 npm registry 审计：0 项已知漏洞。这是当时审计结果，不保证不存在未知问题。
- macOS/Linux、所有商业模型端点及所有第三方 MCP 服务未在本轮实测。
- 以前的免费模型对比仍包含未在首轮完成、需要续跑的案例；本地夹具验收证明调用和权限链可用，不能据此声称模型能力排名或普遍性能优势。
- CLI 工作目录和只读控制不是操作系统沙箱；自动审批下 shell 仍拥有当前用户权限。

图表依赖已升级，审计中的高等级受影响依赖项从 6 个降至 0 个，SVG/PDF/Word 导出回归通过；仍有 7 个中等级受影响依赖项集中在桌面自动化图像依赖链（来自同一条 file-type 公告，不是 7 个独立漏洞）。当前 Electron 31.7.7 的升级迁移、桌面安装包/签名/更新流程及更广泛的真实环境验证仍待完成。

```powershell
npm audit --omit=dev --registry=https://registry.npmjs.org --prefix C:\Path\To\ExtractedPackage
```
