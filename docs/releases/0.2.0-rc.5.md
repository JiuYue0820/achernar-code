# Achernar CLI 0.2.0-rc.5

This candidate is for the standalone coding CLI. The desktop application remains in testing and is not part of this release. npm registry publication still requires maintainer account setup.

## Changes

- Model reasoning controls: `/reasoning`, custom labels/API values, saved per-model settings and provider defaults. Model menus support editing and deletion with visible shortcuts.
- Running tasks keep the command palette available. User prompts use compact gray panels with copy/rewind actions; `/shortcuts` configures keys. Tool and thinking details start collapsed.
- Drag selection freezes the displayed frame while the task continues, so animation does not erase the selection. Ctrl+C copies the selection; Escape resumes the live view.
- `/language` adds Russian alongside Chinese, English and Japanese choices. Commands, model identifiers, source files and model output retain their original text.
- Web search now handles direct fallback result links and long mixed-language queries, reports when it simplifies a query and retains an explicit error when sources cannot be reached.
- Commands, keyboard routing, model management, configuration saving, selection and update handling now have separate modules. Parsed configuration is cached with file-change invalidation. Machine errors preserve service codes and classify common failures.
- ESLint, Prettier, strict mode and coverage reporting are part of the CLI development workflow.
- Clean-checkout evaluation creates missing parent directories without overwriting earlier runs. LSP uses canonical project roots so macOS aliases and Windows junction/short-name paths return correct relative locations. Job Object tests distinguish an enforced process cap from an accidental timeout.
- Windows process-limited commands use framed configuration input and preserve CMD quoting. The environment retains required Windows startup variables while excluding provider credentials and Node injection options.
- `/update` and `achernar update` check the official registry. Installed users receive a cached startup notification when a newer release exists. Installation is explicit, version-pinned and blocked during a task; configuration and conversations remain in the user home directory.
- CLI-only tag publication checks all three desktop OS families on Node 22/24, validates the actual npm tarball and uses npm trusted publishing after account setup. Preview releases use `next`; stable versions use `latest`. Preview installations can advance to a newer stable version.
