# Achernar Code 0.2.0-rc.3

- Split the shared tool implementation into a coding core and a desktop adapter. The CLI does not ship desktop control, visible-browser automation, pet/appearance/voice resources or the desktop agent policy. The desktop application retains its own capabilities.
- Add real, bundled JavaScript/TypeScript LSP: document symbols, cross-file definitions and references, hover/type information, synchronized compiler diagnostics. Queries reread changed files; results are bounded and edits are not exposed through LSP. Other languages retain text search and compiler/test workflows.
- Select a shell with `--shell` or `/shell`: PowerShell, PowerShell Core, CMD, sh, Bash or Zsh. `auto` uses PowerShell on Windows and sh elsewhere. Explicit shells must be installed.
- Add opt-in Docker **terminal isolation**, with no network, a read-only container root, a writable admitted workspace, resource limits and owned-container cleanup. No implicit image pulls and no host fallback. Host MCP and LSP are disabled in this mode. Native file tools, model requests and web research remain outside this boundary; this is not a sandbox of the entire CLI.
- Add VS Code task integration (`achernar ide`, `--write` to merge), and portable hashed extension bundles (`extensions pack/import`). Imports do not execute code, and imported MCP stays disabled. These are distribution building blocks, not a marketplace or a claim of community adoption.
- Doctor reports shell availability, isolation boundaries and language-tool versions. Minimum Node is 22.22.2.

Historical model evaluations remain unchanged and explicitly identify `space-bunny-free` through OpenCode Zen. New language-service and package checks are deterministic engineering tests, not new model benchmarks.
