# Achernar Code 0.2.0-rc.7

CLI only. The desktop application remains in testing.

- Sessions belong to the exact launch directory or explicit `-C` directory. Nested
  folders have separate histories; symlinks to the same physical folder share one.
  Matching legacy sessions remain accessible without bulk migration or deletion.
- First entry asks whether to trust the canonical project directory. Cancel is the
  default. Trust precedes project instructions, task-file reads, tools and models.
  `/cd` asks before switching. Automation must explicitly use `--trust-project`;
  automatic operation approval does not grant project trust. `trust revoke`
  removes the remembered choice.
- Corrected task notifications: noninteractive runs are silent, resolved requests
  cancel pending notifications, and interrupted/blocked output is not a success.
- Known model capacities and reasoning choices are filled from the versioned
  catalogue. The DeepSeek Flash output ceiling is no longer the CLI's old 4,096
  token default. `/output-limit auto` restores automatic limits; explicit custom
  limits and the per-invocation flag remain available.
- Automatic compression reserves space for output, reduces old tool results and
  reasoning, and retains current requests and denied operations. Saved history
  is preserved.
- Truncated generations can continue up to three times within task/cost limits.
  Incomplete tool-call batches never execute; the model must reissue smaller
  complete calls.

Read `docs/model-capabilities.md` for exact supported model IDs, source dates and
limits. Unlisted/custom deployments are not assigned guessed capacities.

Validation uses deterministic local HTTP fixtures plus actual file, shell, LSP,
checkpoint and installed-package checks. This release makes no new model-quality
benchmark claim and no comparison with other products.
