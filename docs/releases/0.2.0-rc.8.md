# Achernar Code 0.2.0-rc.8

CLI only. The desktop application remains in testing.

- **Prompt caching works across rounds.** The per-round budget and live execution mode no
  longer rewrite the system prompt; they travel in a short trailing note. The request prefix
  stays byte-identical, so providers with automatic prefix caching can reuse it. `totalUsage`
  now includes `cached_tokens` when the provider reports it (DeepSeek, OpenAI, Anthropic).
- **Request deadline measures inactivity.** `requestTimeoutMs` (default 180 s) now resets on
  every received chunk. Long, steadily streaming responses are no longer cut off; stalled
  connections still are.
- **Timeouts report correctly.** A task deadline or cancellation no longer crashes with
  "Cannot set property message"; JSON output reports `TASK_TIMEOUT` / `TASK_CANCELED` with the
  `resume <id>` hint.
- **Leaked DeepSeek tool syntax is repaired.** When a model embeds its native DSML parameter
  markup inside a JSON string argument, the parameters are split back out instead of failing
  validation and forcing the whole file to be resent. Existing keys are never overwritten.
- Coding policy: after a rename, search the whole project, including docs, for the old name.
- Windows Job mode retries its helper compile in the per-user temp folder when an inherited
  system TEMP loses the generated source.

Internal measurement (not a ranking): on a fixed 10-task suite with `deepseek-flash` through
`https://api.deepseek.com/v1`, reported cached prompt tokens went from 6% to 88% of prompt
tokens, with the same 9/10 tasks passing. One sample per configuration; the numbers describe this
development run, not a guaranteed saving.

Validation uses deterministic local HTTP fixtures plus actual file, shell, LSP, checkpoint and
installed-package checks on Windows, macOS and Linux CI.
