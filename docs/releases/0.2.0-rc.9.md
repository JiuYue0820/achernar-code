# Achernar Code 0.2.0-rc.9

CLI only. The desktop application remains in testing. This candidate carries the
reliability, performance and localization work layered on top of rc.8.

- **The CLI starts about 45% faster.** `--version` measured 240 ms → 131 ms on the
  reference Windows machine: the MCP SDK and the argument validator (ajv) now load
  on first use instead of at startup, so `--help`, `--version` and config commands
  never pay for them.
- **Session persistence is no longer quadratic.** rc.8 rewrote the whole session
  JSON synchronously on every tool event, which slowed long tasks down over time.
  Writes are now coalesced behind a short debounce, serialized off the hot path,
  and flushed before the task lock is released and at process exit.
- **Automatic file diagnostics reuse a warm worker.** Instead of spawning a fresh
  worker that reloads the TypeScript compiler for every written file, one worker
  per project stays warm (tsconfig cached by mtime). Repeat diagnostics measured
  349 ms → 140 ms; a hung run is still killed by the same 10-second deadline.
- **Context compaction lands at roughly 40% of the window.** A deterministic task
  ledger (exact requests, changed files, commands, failures, plan state) carries
  continuity that a model summary cannot be trusted to restate. Summaries are
  structured TASK/DONE/NOW/DATA at most 200 words, stale tool outputs are pruned
  once usage drifts past 60% of the window, and old synthetic notes are rebuilt
  instead of fed back so the summary chain cannot snowball.
- **Search and range reads are faster.** File search reads candidates with bounded
  concurrency over a short-TTL inventory cache; reading a line range no longer
  splits the entire (up to 1 MB) file.
- **The interactive host UI is localized.** The slash-command handlers, settings
  workbench, approval chooser, model picker and wizard, reasoning menu, update
  menu, agent questions, integration library and the banner tagline now follow the
  configured language (English, 简体中文, 日本語, 한국어, Español, Русский).
  Error messages, machine-readable JSON and model-facing policy text stay in
  English by design.

