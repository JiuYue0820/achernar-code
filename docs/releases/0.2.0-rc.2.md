# Achernar Code 0.2.0-rc.2

Standalone CLI preview · September 2026

This release makes the CLI independently installable with npm from its GitHub release tarball. Public npm registry publication remains pending authentication.

## Included

- `achernar` command, Node.js 22+ support, exact direct dependency versions.
- English/Chinese introductions, detailed usage, release notes and resource notices.
- Live approvals, read-only modes, resumable sessions, model/MCP/Skills/Plugins management.
- 18 official Skills, 11 official Plugins and three original UI templates.
- JSON/JSONL results, task budget notices, recoverable failures and foldable terminal output.
- Standalone tests, package-install checks and a GitHub Actions workflow.
- Achernar-only evaluation data with incomplete tasks and missing token measurements disclosed.

## Installation

```powershell
npm install -g https://github.com/JiuYue0820/achernar-code/releases/download/v0.2.0-rc.2/achernar-code-0.2.0-rc.2.tgz
achernar --version
```

The npm registry command `npm install -g achernar-code@next` should only be used after registry publication is confirmed.

## Validation and scope

See `docs/EVALUATION.md` for Achernar's measured task results and the current candidate's validation records. Development benchmarks predate this distribution revision; they are not all fresh runs of this exact tag. No comparison with other compilers or coding agents is included.

**Recorded real-task model: `space-bunny-free`, served by OpenCode Zen at `https://opencode.ai/zen/v1`, using OpenAI-compatible Chat Completions on 2026-09-26.** Automated functional checks instead use a deterministic local fixture and are not model-quality benchmarks.

The desktop application, native speech and desktop automation runtimes are excluded. The CLI's permission checks are not an OS sandbox. Achernar has not selected an open-source license for its own code; third-party notices remain in place.
