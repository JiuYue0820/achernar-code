# CLI 后续检查与修复

日期：2026-09-27。延续 P0/P1/P2 改进清单，检查已实现功能之间的衔接。没有覆盖已有桌面修改、改变用户模型配置、提交、推送或发布。

## 本次修复

1. **Hooks 遗漏控制类工具。** 工作目录操作、执行模式切换和子代理委派现在经过同一套 pre/post 处理。拒绝委派会在子代理请求模型前停止；子代理内部工具仍单独经过 Hooks。保留原有审批与只读限制。
2. **自动重试漏算潜在费用。** 模型服务收到请求后断开连接，之前重试成功只记录最后一次用量。现在按每次发送分别结算：明确 HTTP 拒绝按未生成处理；无法确认用量的网络中断保守计费。下一次请求发送前重新检查剩余预算；在退避等待中取消不会记入未发送的请求。
3. **独立评测配置串用。** 覆盖端点或接口格式时不读取旧配置的已保存密钥，覆盖模型时不沿用旧费率或上下文容量。无效阈值或缺失预算费率在生成产物、请求模型之前被拒绝。
4. **失败评测丢失用量。** 报告保留失败前已收到的 Token 和最后费用状态；`usageComplete:false` 明确表示不完整。一个响应中多次累计用量通知只计算最后一次，避免重复累加。
