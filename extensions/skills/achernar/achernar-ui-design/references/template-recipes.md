# 模板选型与改造

三个模板为 Achernar 原创，随官方 Skill 提供，允许用于并修改为生成的用户项目；没有下载第三方付费模板、照片或字体。主题图标采用 Lucide 的 sun/月亮路径（ISC，版权声明保留在文件内）。设计原则的出处见 `design-sources.md`，不代表代码来自这些站点。

## 工作台 workbench

导航 → 工作清单 → 当前条目详情。适合用户反复处理对象的工具，不用作营销首页。

- `items` 是示例数据，`render()` 同时更新筛选结果和选中状态，`selectItem()` 更新详情。
- 修改任务字段、筛选条件、详情动作；新的动作要有真实处理结果。
- 桌面使用固定导航宽度与弹性内容，窄屏把详情排到清单后。保留空结果说明与键盘按钮。

## 数据概览 data-overview

大标题与时间控制 → 3 个量化指标 → 主图 → 精确数据表。图表是 SVG，未加载图表库。

- `periods` 使用明确标注的示例数据，`render()` 派生总数、均值和最大值，图与表共享同一组数据。
- 修改时写出单位和采样周期；没有基期不要伪造同比。多系列/统计图使用项目已有库或 Vega-Lite，不不断扩充手写图表引擎。
- 保留表格用于精确读取与无障碍；标签长时换行，数值轴不要截断成误导比例。

## 内容展示 editorial

刊物式大标题 → 索引筛选 → 非等宽主次内容。适合文章、案例、知识目录，不用虚假客户评价和无效订阅表单填充。

- `articles` 是示例内容，`render()` 输出 `<details>` 文章，原生支持键盘展开。
- 修改品牌、类别与正文；长文用真实路由或文档页；不要塞入没有目的的大面积装饰。

## 修改后的验证

在 1366px 与 390px 宽度检查深浅色、最长真实内容和零结果。操作搜索/筛选/详情/主题，检查键盘焦点与刷新后的主题保存。检查无横向整页溢出和控制台错误。截图必须看过才可确认视觉；只有 DOM 测试时说明未做视觉验证。示例不含后端，不能宣称数据同步、登录或多人协作已完成。

CLI 中先检查项目已有浏览器测试入口或已安装的 Playwright。若没有可用浏览器测试工具，做语法与静态检查并明确视觉/交互未验证；不要为一次小页面交付临时自制 CDP/WebSocket 测试框架。用户明确要求建立测试设施时再实现。检查通过后补齐 README 等交付物并结束，不无限扩展测试范围。只关闭本次启动并记录 PID 的进程，不能按浏览器名称批量结束用户进程。
