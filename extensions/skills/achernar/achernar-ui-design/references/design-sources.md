# 高质量参考的筛选与蒸馏

核验日期 2026-09-26：

1. https://fluent2.microsoft.design/layout ：间距表示关系、4px 节奏、响应式密度。应用：用少量稳定间距分组，减少冗余线框，留白突出当前任务。未复制其品牌视觉或组件代码。
2. https://uideck.com/license ：模板分类和许可限制。可用于寻找同类站点布局，具体产品另查许可；免费产品不一定可商用或去署名。
3. https://vega.github.io/vega-lite/docs/ ：有分析图表的产品优先用真实数据视图，而非装饰性“仪表盘”。
4. https://primer.style/ ：GitHub 将 Product UI、Brand UI 和共享基础分开，并提供颜色/间距/字体 tokens 与 Octicons SVG 图标。应用：先判断是操作型产品还是品牌展示，用统一 tokens 和现成 SVG 库保持一致，不把营销视觉套到工作台。

用户提供的 UIBundle、PixEden、PSDrepo、Sketch App Sources、UIdeck、GraphicBurger 和“五艺网”是检索线索。除上方已核验内容，其余本站质量、可访问性与具体素材许可未统一确认；先搜索官方域名并打开实际条目，不杜撰域名、授权或下载链接。不要整站批量复制。图标另选维护中的 SVG 库。

按任务找原型：工作台看编辑器/设计系统的真实应用，内容产品看排版和阅读密度，电商看筛选/商品比较，管理工具看表格/批量操作。优秀参考需同时满足内容可信、流程可用、无明显响应式破损。只抽取 3–5 条与本次任务有关的模式，写入项目笔记并实现。

可进一步检索 IBM Carbon、GOV.UK Design System 的当前组件文档，打开实际页面后再引用。搜索失败时说明未取得新参考，使用上方已核验的原则完成任务。
