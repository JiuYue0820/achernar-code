# Achernar Electron UI

沿用 Achernar 当前黑白中性表面、克制的连续曲率圆角、SVG 图标按钮与中文文案；不恢复旧浅蓝主题。用户明确指定的品牌模式词紫色雾气动效保留，不扩散为全站渐变。一般软件/网页设计另读 achernar-ui-design。给动态节点稳定的 id 或 data 属性，保证容器边界明确；按钮、菜单、弹窗、加载、错误和空状态都要有可操作反馈。

同时检查 1200 x 800 与宽桌面、深浅主题、菜单点击外部关闭、键盘焦点和重启恢复。DOM 断言不能代替截图与计算几何检查；动态初始化后再取快照。文字不得溢出或遮挡相邻控件。
