# 文档与公式参考

2026-09-26 核验：

- Fluent 2 Layout: https://fluent2.microsoft.design/layout 。采用空间表达分组，4px 节奏；可以迁移为文档标题、表格与说明之间稳定的留白，不照搬控件。
- Vega-Lite: https://vega.github.io/vega-lite/docs/ 。声明式数据、聚合、坐标、图例、误差带、分面；适合可复算的报告图表。
- KaTeX 支持表: https://katex.org/docs/supported.html 。仅使用支持的命令，渲染错误要修复，不能隐藏。
- UIdeck 许可: https://uideck.com/license 。部分免费产品仅个人使用且需保留页脚；付费许可也有限制。不能把“免费”理解为可商业再分发。

模板检索按受众与用途，例如“annual report typography grid template”“学术论文 官方 模板 docx”“技术白皮书 template”。优先实际收件机构的官方模板；学校、期刊有格式规范时使用它们。记录模板 URL、访问日期、具体采用的结构。无法联网时采用内置报告布局并说明未检索新模板。

设计图示与许可是不同问题：借鉴字阶、分组和留白不等于复制品牌、图标包或整套收费模板。只读取当前任务需要的 2–3 个来源，停止无目的漫游。
